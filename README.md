## jellyfin-web-open-in-player

Inject script to add `Open in Media Player` to Jellyfin web UI.

This allows you to play item in VLC without copy-pasting URL by utilizing custom `vlc://` URI scheme (you can use [vlc-protocol](https://github.com/stefansundin/vlc-protocol) to register it on your system).

You can use [JavaScript Injector](https://github.com/n00bcodr/Jellyfin-JavaScript-Injector) plugin to inject the script automatically.
